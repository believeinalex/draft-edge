How the numbers are built

Standings are the Yahoo snapshots saved in the repo, {{NSNAPS}} of them from {{FIRST}} to {{ASOF_SHORT}}, spaced unevenly. Velocity compares checkpoints: {{CHECKPOINTS}}. Per-game rates use the change in team games played. Gaps and rank charts use all ten snapshots on a true time axis. Projections apply the draft-day player projections to current rosters, so a team that traded heavily is compared with the roster it has now. The page is rebuilt by season/viz/build_velocity.js each time the morning run completes.
